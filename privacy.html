Privacy policy

Last updated: October 18, 2026

David Merritt uploads is a personal tool run by the owner of the David Merritt Invests and David Merritt YouTube channels. It is used only by that owner, on their own computer.

What it accesses

With the owner's Google sign-in, it uses the YouTube Data API to upload videos to the owner's channels, add captions, add videos to the owner's playlists, and set their details, visibility and publish time. It does not read, collect or store data about any other person.

What it stores

The sign-in token is kept only on the owner's computer. No data is sold, shared or sent anywhere other than YouTube.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
